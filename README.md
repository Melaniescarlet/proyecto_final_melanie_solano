
## Sistema de Reservas CineMax.

¡Bienvenid@ a mi proyecto final para la asignatura de Programación! Este es un sistema interactivo en consola desarrollado en **Python** para gestionar la cartelera, consultar asientos y realizar reservas o cancelaciones en un cine.

---

##  Características Principales.

- **Cartelera Semanal:** Consulta las películas disponibles por cada día de la semana.
- **Mapa de Asientos Visual:** Muestra una matriz de 5x6 (30 asientos por función) identificando asientos libres (`.`) y ocupados (`X`).
- **Gestión de Reservas:** Permite reservar asientos específicos (ej. `C3`, `A1`) validando su disponibilidad.
- **Cancelación de Entradas:** Libera asientos en caso de cancelación.
- **Reporte de Ocupación:** Muestra estadísticas en tiempo real del porcentaje de ocupación por sala y día.
